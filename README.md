## About Me

I hold an M.Sc. in Computer Engineering (Computer System Architecture), with a research background in Computer Vision, Digital Image Processing, and Image Forgery Detection.

My M.Sc. research focused on hybrid feature extraction for Copy-Move Forgery Detection using local and frequency-domain features. I have developed Python-based research projects in Computer Vision, Medical Image Analysis, and Machine Learning.

## Selected Research Projects

### 🔹 Hybrid Copy-Move Forgery Detection

Python reimplementation of a hybrid Copy-Move Forgery Detection methodology combining LBP, DWT, and SIFT features with feature matching, decision fusion, and spatial verification.

[View Repository](https://github.com/shirinnayerdin/copy_move_forgery_detection)

### 🔹 Machine Learning-Based Copy-Move Forgery Detection

Supervised machine learning approach for copy-move forgery detection using SIFT, DWT, Multi-Scale LBP, and SVM classification.

[View Repository](https://github.com/shirinnayerdin/Copy-Move-Forgery-DetectionML)

### 🔹 Brain Tumor MRI Segmentation

Implementation and comparison of classical computer vision techniques, including Otsu Thresholding, K-Means Clustering, and Watershed, for brain tumor MRI segmentation.

[View Repository](https://github.com/shirinnayerdin/Brain-Tumor-Segmentation)

### 🔹 Brain Tumor MRI Classification Using Machine Learning

Classical machine learning pipeline for four-class brain MRI classification using intensity and GLCM texture features with SVM, including hyperparameter tuning and quantitative performance evaluation.

[View Repository](https://github.com/shirinnayerdin/Brain-Tomur-ML-Classification)

### 🔹 Brain Tumor MRI Classification Using Deep Learning

Deep learning study for four-class brain MRI classification comparing a custom CNN with ResNet18 transfer learning and fine-tuning. The experiments examine generalization, class imbalance, and class-specific performance

[View Repository](https://github.com/shirinnayerdin/Brain-Tumor-MRI-Deep-Learning)
